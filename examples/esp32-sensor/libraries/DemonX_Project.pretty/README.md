# DemonX Project footprint library

`Coilcraft_XGL4020_222MEC.kicad_mod` is a DemonX-authored KiCad footprint for
Coilcraft part XGL4020-222MEC (2.2 µH). The two 0.98 × 3.4 mm pads are spaced
2.37 mm center-to-center, following Coilcraft's recommended land-pattern
callouts in [XGL4020 datasheet, document 1529-3](https://www.coilcraft.com/getmedia/76c9c081-4945-4c85-9129-9356e1ad6734/xgl4020.pdf),
revision 2026-02-19. Body outline dimensions are 4.0 × 4.0 mm. This text
footprint artwork is released CC0-1.0; Coilcraft product and documentation
remain property of Coilcraft. No manufacturer 3D model is included.

The part selection is only a prototype candidate. Recompute regulator peak and
ripple current, confirm the chosen inductor's current/temperature margins and
layout, and review the final footprint in KiCad before manufacture.
